Newton-Raphson para n equações 
1. chute inicial X₀
2. monte F(Xi) e o Jacobiano Z = ∂fk/∂xj em Xi
3. resolva o sistema linear  Z·ΔX = −F(Xi)      (eliminação de Gauss)
4. Xi+1 = Xi + ΔX
5. repita até max|Δxj| ≤ ε

É a forma [Z]{Xi+1} = −{Fi} + [Z]{Xi} da aula, escrita em termos de ΔX. Cada iteração troca o sistema não-linear por um sistema linear — por isso a página de sistemas lineares é pré-requisito desta.

Aqui as derivadas do Jacobiano são calculadas por diferença centrada, (f(x+h) − f(x−h))/2h com h = 10⁻⁶·máx(1, |x|). O erro dessa aproximação fica na casa de 10⁻¹⁰ — irrelevante para a tolerância de 10⁻⁴ da lista, mas é o motivo de o resíduo final não zerar até o último bit.

Ponto fixo (substituição progressiva) 
1. reescreva cada equação como  xj = gj(x₁,…,xn)
2. avalie todas as gj com os valores da iteração anterior
3. repita

Condição suficiente de convergência, para duas equações: |∂u/∂x| + |∂u/∂y| < 1 e |∂v/∂x| + |∂v/∂y| < 1 nas funções já isoladas. É um critério restritivo, e um mesmo sistema pode divergir num rearranjo e convergir noutro — o exemplo da Aula 9 mostra exatamente isso.
