Qual método usar

  1. As incógnitas aparecem só multiplicadas por constantes (ou por funções de parâmetros)?

    É um sistema linear, A·x = b. Para poucas incógnitas, use eliminação de Gauss com pivotação: resposta exata em um número fixo de operações. Para sistemas grandes e diagonalmente dominantes, Gauss-Seidel costuma sair mais barato. Abrir sistemas lineares

  2. Há uma única incógnita dentro de uma função não-linear (sen x, eˣ, x³…)?

    É uma equação não-linear, f(x) = 0. Se você consegue cercar a raiz num intervalo com troca de sinal e quer garantia, use bissecção ou regula falsi. Se tem um bom chute e quer rapidez, Newton-Raphson (com derivada) ou secante (sem derivada). Abrir equações não-lineares

  3. Várias incógnitas e pelo menos uma equação não-linear nelas?

    É um sistema não-linear, F(X) = 0. Newton-Raphson é o padrão: converge rápido a partir de um chute razoável. O ponto fixo é mais simples de montar, mas só converge para rearranjos favoráveis. Abrir sistemas não-lineares

Sistemas lineares

Resolver A·x = b com n equações e n incógnitas. Os métodos diretos chegam à solução em um número finito e previsível de operações; os iterativos partem de um chute e o refinam até o erro ficar abaixo da tolerância. Resolver na ferramenta

Eliminação de Gauss direto

Transforma o sistema num sistema triangular superior equivalente e resolve de baixo para cima.

1. para cada coluna k = 1 … n−1 (o pivô é akk):
     para cada linha i abaixo de k:
       m = aik / akk
       linha i ← linha i − m · linha k      (inclui b)
2. substituição regressiva:
     xn = bn / ann
     xi = ( bi − Σj>i aij·xj ) / aii,  i = n−1 … 1
Precisa de
A e b; nenhum chute inicial
Resultado
exato, a menos do arredondamento
Custo
cerca de 2n³/3 operações — cresce rápido com n

Falha quando algum pivô akk é zero (divisão por zero), mesmo que o sistema tenha solução. Pivôs muito pequenos não travam o método, mas amplificam o erro de arredondamento.

Resolver com eliminação de Gauss

Gauss com pivotação parcial direto

A mesma eliminação, mas antes de zerar cada coluna troca a linha do pivô pela que tem o maior |aik| naquela coluna.

1. para cada coluna k:
     encontre p ≥ k com o maior |apk|
     troque as linhas k e p                (em A e em b)
     elimine abaixo do pivô como no Gauss simples
2. substituição regressiva
Precisa de
A e b
Vantagem
evita pivô nulo e mantém os multiplicadores |m| ≤ 1, o que reduz o erro de arredondamento
Custo
o mesmo do Gauss, mais as comparações para achar o maior pivô

Falha quando a coluna inteira abaixo do pivô é zero: aí a matriz é singular e o sistema não tem solução única — nenhum método direto resolve.

Resolver com pivotação

Gauss-Jordan direto

Elimina acima e abaixo de cada pivô e normaliza o pivô para 1. A matriz vira a identidade e a solução aparece direto no vetor b.

1. para cada coluna k:
     linha k ← linha k / akk          (pivô = 1)
     para toda linha i ≠ k:
       linha i ← linha i − aik · linha k
2. ao final, [A | b] = [I | x]  →  x = b
Precisa de
A e b
Vantagem
dispensa a substituição regressiva; aplicado a [A | I], devolve a inversa A⁻¹
Custo
cerca de n³ operações — em torno de 50 % a mais que o Gauss

Falha quando encontra pivô nulo, pelo mesmo motivo do Gauss simples. Para só resolver o sistema, raramente compensa o custo extra.

Resolver com Gauss-Jordan

Jacobi iterativo

Isola a incógnita da diagonal em cada equação e recalcula todas ao mesmo tempo, usando só os valores da iteração anterior.

1. chute inicial x⁽⁰⁾ (vazio = zeros)
2. para cada i:
     xi⁽ᵏ⁺¹⁾ = ( bi − Σj≠i aij·xj⁽ᵏ⁾ ) / aii
3. repita até εa < εs para todas as incógnitas
Precisa de
A, b, chute inicial e critério de parada
Converge se
A for estritamente diagonalmente dominante: |aii| > Σj≠i |aij| em toda linha (condição suficiente, não necessária)
Custo
cerca de n² operações por iteração; guarda dois vetores (anterior e novo)

Falha quando a matriz não é dominante: a iteração pode oscilar ou divergir. Reordenar as equações para pôr os maiores coeficientes na diagonal muitas vezes resolve.

Resolver com Jacobi

Gauss-Seidel iterativo

Igual ao Jacobi, mas cada valor recém-calculado já entra nas equações seguintes da mesma iteração.

1. chute inicial x⁽⁰⁾
2. para i = 1 … n, em ordem:
     xi⁽ᵏ⁺¹⁾ = ( bi − Σj<i aij·xj⁽ᵏ⁺¹⁾ − Σj>i aij·xj⁽ᵏ⁾ ) / aii
3. repita até εa < εs
Precisa de
A, b, chute inicial e critério de parada
Converge se
a mesma condição suficiente do Jacobi (dominância diagonal)
Vantagem
em geral precisa de menos iterações que o Jacobi e sobrescreve um único vetor, ocupando menos memória

Atenção: "em geral" não é "sempre" — existem matrizes em que o Jacobi converge e o Gauss-Seidel não. O resultado também depende da ordem das equações.

Equações não-lineares

Encontrar x tal que f(x) = 0. Os métodos de confinamento mantêm a raiz presa num intervalo e nunca escapam; os métodos abertos partem de pontos que não precisam cercar a raiz, convergem muito mais rápido e podem divergir. Resolver na ferramenta

Bissecção confinamento

Divide o intervalo ao meio a cada passo e fica com a metade onde f troca de sinal.

1. escolha [a, b] com f(a)·f(b) < 0
2. xm = (a + b) / 2
3. se f(a)·f(xm) < 0:  b = xm
   senão:                a = xm
4. repita até (b − a)/2 < ε  ou  |f(xm)| < tolerância
Precisa de
um intervalo [a, b] com troca de sinal; f contínua
Converge?
sempre, se houver raiz no intervalo
Velocidade
linear — o erro cai à metade por iteração; dá para prever o número de iterações: n ≥ log₂((b − a)/ε)

Limitações: ignora o valor de f (só usa o sinal), por isso é lenta. Não acha raízes em que f toca o eixo sem cruzar (raiz dupla) e, se o intervalo contém várias raízes, encontra só uma delas.

Resolver com bissecção

Regula falsi (falsa posição) confinamento

Liga (a, f(a)) e (b, f(b)) por uma reta e usa o ponto onde ela corta o eixo x como nova estimativa — no lugar do ponto médio.

1. escolha [a, b] com f(a)·f(b) < 0
2. xr = b − f(b)·(a − b) / ( f(a) − f(b) )
3. se f(a)·f(xr) < 0:  b = xr
   senão:                a = xr
4. repita até |xr⁽ⁱ⁺¹⁾ − xr⁽ⁱ⁾| < ε  ou  |f(xr)| < tolerância
Precisa de
o mesmo que a bissecção
Converge?
sempre, se houver raiz no intervalo
Velocidade
linear, mas quase sempre mais rápida que a bissecção porque aproveita o valor de f

Falha quando a função é muito curva perto da raiz: um dos extremos fica travado e o intervalo quase não encolhe. No exemplo x¹⁰ − 1 da ferramenta, após cinco iterações a bissecção está em 1,6 % de erro e a regula falsi ainda em 59 %.

Resolver com regula falsi

Newton-Raphson aberto

Traça a reta tangente a f no ponto atual e toma como próxima estimativa o ponto onde a tangente corta o eixo x.

1. chute inicial x₀
2. xi+1 = xi − f(xi) / f′(xi)
3. repita até |xi+1 − xi| < ε  ou  |f(xi+1)| < tolerância
Precisa de
um chute x₀ e a derivada f′(x) — na ferramenta, se não for dada, é estimada por diferença centrada
Converge?
não necessariamente — depende de x₀ estar perto da raiz
Velocidade
quadrática perto de uma raiz simples: o número de dígitos corretos aproximadamente dobra a cada iteração

Falha quando f′(xi) ≈ 0 (a tangente é quase horizontal e o passo explode), quando o chute está longe e as iterações oscilam ou divergem, ou em raízes múltiplas, onde a convergência cai para linear.

Resolver com Newton-Raphson

Secante aberto

Newton-Raphson sem derivada: troca a tangente pela reta secante que passa pelas duas últimas estimativas.

1. dois chutes x₋₁ e x₀
2. xi+1 = xi − f(xi)·(xi−1 − xi) / ( f(xi−1) − f(xi) )
3. descarte o ponto mais antigo e repita
Precisa de
dois chutes, que não precisam cercar a raiz
Converge?
não necessariamente
Velocidade
superlinear, ordem ≈ 1,618 — um pouco mais lenta que Newton por iteração, mas cada iteração só avalia f uma vez

Diferença para a regula falsi: a fórmula é parecida, mas a secante sempre descarta o ponto mais antigo, sem verificar o sinal. Por isso é mais rápida — e pode divergir. Se f(xi−1) ≈ f(xi), o denominador vai a zero.

Sistemas não-lineares

Resolver F(X) = 0, com várias equações e várias incógnitas, sendo pelo menos uma equação não-linear. Os dois métodos são abertos: partem de um chute para cada incógnita e nenhum dos dois tem convergência garantida. Resolver na ferramenta

Newton-Raphson para n equações aberto

Generaliza o Newton de uma variável: em vez da derivada, usa a matriz jacobiana, e em vez de uma divisão, resolve um sistema linear a cada iteração.

1. chute inicial X₀
2. monte F(Xi) e o jacobiano Zkj = ∂fk/∂xj em Xi
3. resolva o sistema linear  Z·ΔX = −F(Xi)      (eliminação de Gauss)
4. Xi+1 = Xi + ΔX
5. repita até max|Δxj| ≤ ε
Precisa de
um chute para cada incógnita; o jacobiano (na ferramenta, calculado por diferença centrada)
Converge?
não necessariamente — depende do chute
Velocidade
quadrática perto da raiz; no gráfico de erro em escala log, a curva despenca
Custo
n² derivadas e um sistema linear n×n por iteração

Falha quando o jacobiano é singular ou quase singular no ponto atual (o sistema linear não tem solução única), ou quando o chute está longe da raiz. Sistemas com várias soluções convergem para aquela mais "próxima" do chute — nem sempre a fisicamente válida.

Resolver com Newton-Raphson

Ponto fixo (substituição progressiva) aberto

Reescreve cada equação isolando uma incógnita, xj = gj(x₁, …, xn), e reaplica as funções g até os valores pararem de mudar.

1. reescreva cada equação como  xj = gj(x₁,…,xn)
2. avalie as gj:
     simultâneo (Jacobi)      — todas com os valores da iteração anterior
     sucessivo (Gauss-Seidel) — cada uma já com os valores recém-calculados
3. repita até max|Δxj| ≤ ε
Precisa de
um chute para cada incógnita e um rearranjo x = g(x); sem derivadas
Converge se
(condição suficiente, 2 equações) |∂u/∂x| + |∂u/∂y| < 1 e |∂v/∂x| + |∂v/∂y| < 1 nas funções já isoladas
Velocidade
linear — o erro cai por um fator aproximadamente constante; no gráfico log, uma reta

Falha quando o rearranjo é desfavorável. O isolamento não é único, e o mesmo sistema pode divergir num rearranjo e convergir noutro (exemplo da Aula 9). Isolar a incógnita do termo de maior expoente costuma ajudar. A variante sucessiva converge mais rápido quando converge — e diverge mais fácil.

Como os métodos se conectam

  • Newton para sistemas depende de sistemas lineares. Cada iteração resolve Z·ΔX = −F por eliminação de Gauss. Se o método linear falha (pivô nulo, matriz singular), o Newton para sistemas também falha.
  • Newton de uma variável é o caso n = 1. Com uma equação, o jacobiano vira f′(x) e o sistema linear vira a divisão −f/f′.
  • Jacobi e Gauss-Seidel reaparecem no ponto fixo. As variantes simultânea e sucessiva são a mesma ideia dos iterativos lineares: usar só a iteração anterior ou já aproveitar os valores novos. Na verdade, Jacobi e Gauss-Seidel são métodos de ponto fixo, com g vinda de isolar a diagonal de A.
  • Secante é Newton com derivada aproximada. A inclinação da tangente é substituída pela inclinação entre as duas últimas estimativas.
  • Regula falsi e secante usam a mesma reta. A diferença está só em qual ponto é descartado: a regula falsi preserva a troca de sinal, a secante descarta sempre o mais antigo.

Critérios de parada

Todo método iterativo precisa decidir quando parar. As três ferramentas usam variações dos mesmos critérios:

Erro relativo aproximado
εa = |(xnovo − xanterior) / xnovo| · 100 % — usado nos iterativos lineares, para todas as variáveis
Tolerância por algarismos
εs = 5·101−n % garante pelo menos n algarismos significativos corretos (critério de Scarborough)
Passo absoluto
|xi+1 − xi| < ε nos métodos abertos; max|Δxj| ≤ ε nos sistemas não-lineares; (b − a)/2 < ε na bissecção
Resíduo
|f(x)| < tolerância ou ‖F(X)‖∞ — mede se a equação está de fato satisfeita
Máximo de iterações
trava de segurança contra divergência ou convergência lenta demais

Por que usar mais de um: passo pequeno não garante resíduo pequeno (a função pode ser muito íngreme), e resíduo pequeno não garante x preciso (a função pode ser muito plana perto da raiz).
